# 🔎 Research & Report Assistant

A beginner-friendly multi-agent AI research assistant built with:

- Python
- CrewAI
- Groq
- Streamlit

## 🤖 Agents

The system contains four sequential agents:

1. Research Manager
2. Researcher
3. Fact & Source Analyst
4. Report Writer

## 🔄 Workflow

User enters a research topic.

```text
User
 ↓
Research Manager
 ↓
Researcher
 ↓
Fact & Source Analyst
 ↓
Report Writer
 ↓
Final Report
